# ChatGPT Review Pulse — Milestone 5

An interactive prototype that turns a sample of public ChatGPT mobile app review excerpts into a structured product pulse, a facts-only customer clarification, and an approval-gated publishing simulation.

## What it does
- Reads `data/reviews_sample.csv` (17 user-provided review excerpts, dated July 21–September 18, 2026).
- Groups feedback into up to five themes and highlights three leading themes.
- Shows three verbatim review quotes.
- Derives a candidate customer clarification from reviews mentioning free-plan limits, subscription value, and a reported free-trial payment failure.
- Produces a weekly product pulse (under 250 words) and a six-bullet-or-fewer fee/charge explainer with two official OpenAI links.
- Requires an explicit approval checkbox and button before the demo simulates appending a Notes entry and creating an email draft.
- Allows downloading the structured Notes JSON, email draft text, and review sample CSV.

## Run locally
This is a static site; no build step or API key is needed.

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Review the Pulse and Fee Explainer tabs.
4. Go to **Approval & MCP**, inspect the payload, tick the approval checkbox, then click **Approve & run demo actions**.
5. Download the Notes JSON and email draft generated by the demo.

## Approval gate / MCP status
The UI enforces a visible approval step before running the simulated actions. After approval, it adds a Notes entry to the current page's demo log and enables downloads for a JSON document entry and an email draft. This is a **local simulation**, not a live Google Docs/Notion/Gmail MCP connection. To productionize it, replace `runApprovedActions()` with authenticated MCP tool calls for appending to the chosen document and creating (never sending) a Gmail draft; retain the approval gate server-side and log action outcomes.

## Fee issue identified
Reviews mention free-plan feature limits and paid-plan value, and one review (Achlesh Singh, September 11, 2026) reports a failed free-trial payment attempt. The data does **not** prove an incorrect charge or establish the cause of the payment failure. The explainer therefore covers promotional-trial terms, payment method requirements, renewal terms, plan-specific usage limits, and troubleshooting without claiming that a charge was wrong.

## Dataset limitations
The CSV is a curated sample transcribed from review text pasted by the project owner, not a complete scrape or statistically representative sample. It includes only the provided reviews in the selected recent window; the original pasted collection also contained older reviews, which were excluded. Review dates and text are preserved as provided, with light punctuation cleanup in a few long excerpts. Recollect a larger 8–12 week public dataset and validate date/country filters before making population-level claims.
